# Fuze Arena – Hero Battle

Jeu mobile de héros automatique : on invoque des héros, on forme une section de 5 et on enchaîne des
centaines de combats qui se jouent seuls, quelques minutes par jour.

- `src/core/` : les règles du jeu (invocations, fusion, force des héros, économie, campagne)
- `simulations/` : simulations de progression (`npm run simuler`)
- `tests/` : tests automatiques (`npm test`)
- `docs/` : résultats des simulations

Installation : `npm install`.
